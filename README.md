# 📊 Customer Sales Data Analysis

A Python-based data analysis project focused on cleaning, analyzing, and visualizing customer sales data.

## 🎯 Project Overview

This project uses a messy customer sales dataset and follows a basic data analysis workflow:

**Raw Data → Data Cleaning → Data Analysis → Data Visualization → Insights**

The goal was to transform the raw dataset into clean, meaningful information and identify useful sales patterns.

## 🛠️ Tools & Technologies

- Python 🐍
- Pandas
- Matplotlib
- Microsoft Excel
- VS Code

## 🧹 Data Cleaning

The raw dataset was processed using Pandas.

The cleaning process included:

- Checking the dataset size
- Checking missing values
- Checking duplicate rows
- Cleaning customer names
- Cleaning city names
- Standardizing order status
- Saving the cleaned data into a new Excel file

## 📈 Data Analysis

The project analyzes:

- Sales by city
- Revenue by product
- Revenue by category
- Monthly sales trends
- Sales by payment method
- Sales by order status
- Top customers
- Top products by quantity sold

## 📊 Data Visualization

Matplotlib was used to create different visualizations to understand sales patterns.

### Top 10 Products by Quantity Sold

The analysis compares the quantity sold across the top 10 products and helps identify which products had the highest sales volume.

## 🔍 Key Findings

Some observations from the analysis include:

- **Laptop** generated the highest revenue among the products.
- **Smartphone** was another major contributor to total revenue.
- **Webcam** had the highest quantity sold among the products shown in the analysis.
- **Hyderabad** had the highest total sales among the cities shown.
- The analysis also highlights differences in sales based on payment method and order status.
